> **PMFY** 是一款专为 Windows 11 深度打造的现代化、高颜值全局 AI 智能翻译桌面应用。深度融入 Fluent Design 亚克力视觉语言，基于离线 RapidOCR 高速文字检测与顶级 AI 大模型，首创**光标 5 方位快捷轮盘**、**选区截屏原位图像重绘**、**全屏沉浸式翻译**、**划词防误触秒翻**、**独立双语工作台**与**“问 AI”多轮深度导师**。

## 💡 痛点剖析：为什么传统翻译工具总是不好用？

| 传统翻译方案 | 常见致命痛点 | PMFY 的革命性解决之道 |
| :--- | :--- | :--- |
| **浏览器翻译插件**<br>*(如沉浸式翻译/自带翻译)* | 只能在网页浏览器中生效，一旦切换到**桌面客户端、Discord、游戏、PDF 电子书、IDE 代码编辑器、设计软件或图片**，插件彻底瘫痪。 | **全局操作系统级接管**：无论是游戏界面、远程桌面还是本地 PDF，随时随地在任何软件上呼出即用。 |
| **传统截图翻译软件**<br>*(如各类 OCR 翻译小工具)* | 截屏后弹出一个巨大的生硬白色窗口，格式全乱，**遮挡用户的工作区域**，阅读时需要眼睛在原图与弹窗之间反复费劲对照。 | **真正的原位图像重绘 (In-place Replacement)**：自动嗅探原背景色进行智能色块擦除覆盖与文字排版，**译图直接原位取代原图**，保持版面原汁原味。 |
| **传统划词翻译工具**<br>*(如各类悬浮翻译)* | ① 鼠标在空白处长按或手抖时**频繁误弹蓝球**骚扰用户；<br>② 无法感知整页上下文，孤立词汇经常**机翻词不达意**；<br>③ 想深入追问某个语法难点或母语表达时毫无办法。 | ① **Windows 原生 UIA 选区嗅探 + 矢量位移过滤**，彻底杜绝原地长按误触；<br>② **全屏全局语境关联 + 多模态 Vision 图像**注入大模型；<br>③ **无缝直达“问 AI”窗口**，随叫随到，多轮追问。 |
| **传统机械翻译引擎**<br>*(如老旧通用翻译 API)* | 翻译生硬死板，无法根据技术开发、学术论文、游戏本地化、文学阅读等特定场景切换专属语气与术语库。 | **5 大垂直领域 Prompt 专家预设**（通用、学术、技术文档、游戏动漫、文学阅读）+ **最大并发限流控制**。 |

## 🧩 六大核心功能模块详解

### 1. 🎛️ 光标 5 方位快捷轮盘 (Radial Menu / Pie Menu)
- **按住呼出，松开执行**：在任意界面长按快捷键（默认 `Ctrl+Win+Alt`，支持自定义），光标所在处瞬间弹出半透明 Fluent 亚克力圆盘。
- **5 方位布局**：
  - ⬆️ **上方 (North)**：**🖥️ 全屏翻译**（全屏原位 OCR 重绘翻译）
  - ⬇️ **下方 (South)**：**✂️ 选区翻译**（十字准心选区截图原位翻译）
  - ⬅️ **左侧 (West)**：**⚡ 立即翻译模式切换**（一键在“直接弹窗”与“悬浮球”之间切换）
  - ➡️ **右侧 (East)**：**✍️ 输入翻译工作台**（呼出独立双语输入翻译窗口）
  - ⏺️ **中心 (Center)**：**✕ 取消操作**（不执行任何操作直接隐匿）
- 移动鼠标指向对应方位，扇区高亮反馈，**松开快捷键即秒级执行**。

---

### 2. ✂️ 选区截屏原位重绘翻译 (Area Snipping Translation)
- **十字准心框选**：通过轮盘下方或独立快捷键进入选区模式；
- **左键框选**：松开左键立即截取区域，秒级进行 RapidOCR 识别与 AI 原位重绘替换；
- **右键框选**：松开右键在选区边缘弹出确认卡片（`✨ 确认翻译此选区？`），确认后执行；
- **动态胶囊进度条 (Pill Progress HUD)**：实时反馈 OCR 识别、AI 批量翻译与原位重绘百分比进度；
- **二次划词与浮动微导航栏**：翻译完成后可直接在译图上框选文字，进行 **📋 复制**、**🔍 详细翻译** 或 **🤖 问 AI**；
- **丰富工具栏**：支持按住 **👁️ 对比原图**、**📋 复制全部文本**、**💾 保存图片**。

---

### 3. 🖥️ 全屏沉浸式原位图像翻译 (Fullscreen Viewer)
- 一键捕获当前全屏画面，调用 RapidOCR 离线提取所有文字坐标；
- AI 智能上下文连贯翻译，自动进行原背景智能修补（Inpainting）与高对比度文字原位重绘；
- 支持 **按住空格对比原图**、**鼠标滚轮缩放与右键拖拽平移**、**左键框选文字查询** 与 **顶部即时目标语言切换**。

---

### 4. ⚡ 划词“立即翻译”与“悬停翻译”双模式
- **智能防误触过滤**：基于 Windows UI Automation 原生选区嗅探与位移矢量门禁，彻底过滤原地长按与手抖误触；
- **默认悬停模式**：划词释放后在选区边缘显示蓝色防遮挡小圆圈，鼠标悬停时弹出三合一详细翻译卡片；
- **立即翻译模式**：划词释放后跳过悬浮球，直接秒级弹出三合一详细翻译卡片；
- **三合一卡片模块**：可独立开启或关闭【📝 精准译文】、【💡 详细语法词性分析】、【📖 实用双语造句】。

---

### 5. ✍️ 独立双语输入翻译工作台 (Input Translation Studio)
- 类似 Google 翻译 / DeepL 桌面端独立工作台；
- **双向语言管理**：源语言自动识别、目标语言下拉选择与一键互换语言（`⇄`）；
- **实时 500ms 防抖翻译**：输入或修改文本时停顿 500ms 即自动发起翻译，杜绝频繁打字冲突；
- **多维深度解析**：同步展示【📝 译文】、【🔊 语音发音与音标/拼音】、【💡 详细释义与语法分析】、【📖 实用造句】及【🤖 问 AI】。

---

### 6. 🤖 “问 AI” 智能讨论与答疑系统 (Ask AI)
- 携带当前划词或全屏选区原文、译文与全局上下文，呼出置顶智能对话窗口；
- 支持语法难点剖析、近义表达辨析、母语级润色及多轮自由追问，支持边看译图边探讨细节。

## 🛠️ 技术架构与底层依赖

| 模块 | 核心技术 | 功能说明 |
| :--- | :--- | :--- |
| **GUI 框架** | `PyQt6` + `QFluentWidgets` | 深度集成 Windows 11 Fluent Design 原生亚克力毛玻璃视觉 |

## 🚀 源码运行与环境配置指南

### 1. 环境准备
- **操作系统**：Windows 10 / 11 (64-bit)
- **Python 版本**：Python 3.10 或更高版本

### 2. 克隆项目与安装依赖
```bash
# 克隆仓库
git clone https://github.com/your-username/PMFY.git
cd PMFY

# 创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\activate

# 安装全套依赖
pip install -r requirements.txt
```

### 3. 运行软件
- **方式一（推荐）**：直接双击根目录下的 **`启动软件.bat`**（静默常驻任务栏托盘）；
- **方式二（调试模式）**：双击 **`启动软件(带控制台日志).bat`**；
- **方式三（命令行）**：
  ```bash
  python run.py
  ```

### 4. 首次配置
首次启动会自动弹出设置中心，填入您的 **API Base URL**（如 `https://api.openai.com/v1`）与 **API Key**，点击 **测试 API 连接** 并保存即可！
